# UZÁVĚRKA

Narativní horror · ~30 minut · poslední noční směna v aquaparku **Atlantis Wave**.

Hraješ za Elišku. Pojišťovna chce fotky prázdného parku před demolicí.
Park si pamatuje víc než vedení.

## Hrát

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Herní smyčka

- Lokace → prozkoumání → inventář / dokumenty / SMS
- Hádanky (kód jističů, pořadí ventilů)
- Tři konce: **Útěk**, **Svědek**, **Hlubina**
- Uložení do `localStorage`

## Obsah / varování

Smrt dítěte, utonutí, firemní cover-up, psychologický horor.
Fiktivní aquapark — není založeno na skutečném místě.

## Stack

Vite · vanilla JS · Web Audio (procedurální ambient) · žádný backend
